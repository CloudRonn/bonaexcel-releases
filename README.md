# Bonaexcel for Windows

A portable Windows desktop controller for Bonaexcel. It works with Microsoft Excel desktop or WPS Spreadsheets. Connect a Gemini or OpenRouter key in the app.

## Download

Download the latest Bonaexcel.exe from the [releases page](https://github.com/CloudRonn/bonaexcel-releases/releases/latest).
