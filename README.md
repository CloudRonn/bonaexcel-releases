# Bonaexcel for Windows

A portable Windows desktop controller for Bonaexcel. It works with Microsoft Excel desktop and can launch Excel for the web. Install Excel for the desktop workflow. Connect a Gemini or OpenRouter key in the app.

## Download

Download the latest Bonaexcel.exe from the [releases page](https://github.com/CloudRonn/bonaexcel-releases/releases/latest).
